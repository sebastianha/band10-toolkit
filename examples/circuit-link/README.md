# VOID-LINK O66

An alien-reactor face for the Xiaomi Smart Band 10. Eight circuit traces zip
inward, particles converge, dual glyph rings counter-rotate, the core fires two
shockwaves, and the link collapses back into a dormant seed.

## What makes it animate

The centerpiece is a single `animation` widget. An animation on the Band 10 is
**not** a vector tween — it is a sequence of equal-size frame images that the
watch flips through on a fixed interval, exactly like a flipbook.

```jsonc
{
  "id": "assembly",
  "type": "animation",
  "frames": [
    "assets/anim/link-00.png",
    "assets/anim/link-01.png",
    // ... 48 indexed-color frames, all 176×196 ...
    "assets/anim/link-47.png"
  ],
  "intervalMs": 60,   // 60ms × 48 ≈ 2.9s per loop
  "repeat": 0,        // 0 = loop forever
  "x": 18, "y": 190, "z": 3
}
```

The frames themselves are generated by
[`scripts/generate-circuit-link-assets.ts`](../../scripts/generate-circuit-link-assets.ts).
The trace reveal uses SVG paths with `pathLength="100"` and
`stroke-dasharray="<progress> 100"`. Each generated SVG is rasterized to an
opaque, 192-color PNG so native packing can use compact indexed palettes.

## Rules the validator enforces

- Every frame must exist and share identical dimensions.
- `intervalMs` between 16–60000, `repeat` 0–65535.
- **No animation widgets in AOD.** AOD must stay static to protect battery/burn-in,
  so AOD uses a custom sleeping-core `assets/decor/link-static.svg` at low opacity.
- No widget overlap, nothing clipped by the pill edge.

## Build it

```bash
npm run generate:circuit   # regenerate indexed PNG frames + SVG digits
npm run validate:circuit   # schema + overlap + AOD checks
npm run build:circuit      # preview.png + FPRJ + GMF
npm run package:circuit    # dist/circuit-link.face (install via Notify)
npm run screenshots:circuit
```

> Native o66 packing is structurally round-tripped but still requires physical
> Band 10 verification.
